# 第2周：升降算符、模式与零点涨落

先复习 Griffiths 第2章谐振子代数解法，再读 Gerry & Knight 第2章前半。教材正文未随任务提供；以下是独立推导讲义，不冒充教材原文或逐页阅读记录。

## 1. 为什么要重新写谐振子

第1周在坐标空间离散微分方程。第2周选择“能量本征态”作基底：把一个态描述成各能级的概率振幅。微分算符被矩阵代替，光子数态正好适用。

```text
[x,p]=iℏ
a = sqrt(mω/(2ℏ)) x + i p/sqrt(2mℏω)
a†= sqrt(mω/(2ℏ)) x - i p/sqrt(2mℏω)
[a,a†]=1
x = sqrt(ℏ/(2mω)) (a+a†)
p = -i sqrt(mℏω/2) (a-a†)
```

检验对易关系：令A、B分别是x与p的系数，`[Ax+iBp,Ax−iBp]=−2iAB[x,p]=2ABℏ=1`。

## 2. 能级、数态与产生湮灭

```text
n̂=a†a, H=ℏω(n̂+1/2)
a|n⟩=sqrt(n)|n−1⟩
a†|n⟩=sqrt(n+1)|n+1⟩
|n⟩=(a†)^n|0⟩/sqrt(n!), a|0⟩=0
E_n=ℏω(n+1/2)
```

把a†a代回x、p表达式可得到 `H=ℏω(a†a+1/2)`。`[n̂,a]=−a` 说明a让能量少一份ℏω，a†增加一份。这些是算符，`a|0⟩=0`中的右边是零向量，不是基态 `|0⟩`。

“二次量子化”在这里是用模式的占据数和产生／湮灭算符描述状态；每个模式可以有0、1、2…个玻色激发。它不是在已经量子化的同一对象上再按一次按钮。

## 3. 模式为什么像谐振子

在线性电磁场中选定边界条件和正交模式，每个模式的幅度满足谐振子方程。量子化后每个模式带一对a、a†：

```text
H_field = Σ_k ℏω_k (a†_k a_k + 1/2)
[a_k,a†_l]=δ_kl
|n_1,n_2,...⟩是各模式占据数态
```

一个光子表示某个模式多一份ℏω激发。“模式”还包括空间形状、频率、偏振等标签；不能简单地把不同模式等同于不同位置的小球。`tensor`把不同模式或模式与原子组合，系统总维数是各子系统维数的乘积。

例子：`tensor(basis(6,2),basis(2,1))`表示模式在n=2、二能级系统在第1基矢。`tensor(num(6),qeye(2))`只测模式光子数。子系统顺序必须一致。

## 4. 零点能与零点涨落

展开平方，注意算符不交换：

```text
(a+a†)² = a² + aa† + a†a + (a†)²
⟨n|a²|n⟩=⟨n|(a†)²|n⟩=0
⟨n|aa†|n⟩=n+1, ⟨n|a†a|n⟩=n
所以 ⟨n|(a+a†)²|n⟩ = 2n+1
```

在数态中 `⟨x⟩=⟨p⟩=0`，但二阶矩不为0：

```text
Δx² = ℏ(2n+1)/(2mω)
Δp² = mℏω(2n+1)/2
E_0=ℏω/2, 真空中 ΔxΔp=ℏ/2
```

因此“零点涨落验证”与“零点能验证”相关但不相同：前者检查方差，后者检查H期望值。本项目两者都做了。无量纲 `X=(a+a†)/sqrt(2)`、`P=−i(a−a†)/sqrt(2)` 时，真空方差各为1/2，方差的乘积为1/4，标准差的乘积为1/2。别把两种乘积混淆。

## 5. 有限矩阵不可能严格满足[a,a†]=I

任何有限矩阵的对易子迹为0，而I的迹为N，两者不可能恒等。截断基 `|0⟩,...,|N−1⟩` 中：

```text
[a,a†] = I − N |N−1⟩⟨N−1|
```

对远离最高层的数态，期望仍符合无穷维公式；最高态会失败。N=20时，最高态n=19的平方期望为19，不能误用2n+1=39。程序特意展示这个边界反例，并阻止把最高层放进常规验证范围。

动手：选N=8，打印a、a†及对易子的对角；预测最后一个元素是−7；把验证态n从0逐步加到7，解释哪里开始偏离。
