# 第2周：QuTiP、Rabi振荡与热态

## 1. 一张函数对照表

| 函数／对象 | 白话解释 | 亲自检查 |
|---|---|---|
| `Qobj` | 带维数信息的量子向量或算符 | `.shape`, `.dims`, `.isket`, `.isherm` |
| `basis(N,n)` | N维空间的第n个基矢，n从0开始 | `.full()` 查看矩阵 |
| `sigmax/y/z` | 二能级的Pauli算符 | σx²=I，σz对角为+1、−1 |
| `destroy/create` | 玻色模式的湮灭／产生算符 | 升降系数是平方根 |
| `tensor` | 合并多个子系统 | 顺序与每个算符一致 |
| `expect` | 对纯态或密度矩阵求观测量均值 | 实物理量的虚部应仅为舍入误差 |
| `sesolve` | 解封闭系统薛定谔方程 | 检查态范数与解析解 |
| `mesolve` | 解含Lindblad项的主方程 | 检查迹、厄米性、正性 |
| `thermal_dm` | 生成热态密度矩阵 | 截断会影响平均光子数 |
| `QobjEvo` | 表示随时间变的算符 | 函数、字符串或采样数组系数 |

NumPy数组的 `*` 为逐元素乘法、`@` 为矩阵乘法；QuTiP `Qobj` 的 `*` 是算符乘法。把 `.full()` 取出的NumPy数组继续相乘时要换回 `@`。

## 2. 基态约定必须自己定义

`basis(2,0)`本身只叫 `|0⟩`，不天然意味着能量基态。若自由哈密顿量 `H0=ω0 σz/2`，|0⟩能量+ω0/2，反而更高；若取 `H0=−ω0 σz/2`，|0⟩才是基态。

QuTiP的 `sigmam()` 矩阵为 `[[0,0],[1,0]]`，把|0⟩送到|1⟩。若选择g=|0⟩、e=|1⟩，衰减算符应直接写 `g*e.dag()`；不要不看约定就使用sigmam。本项目的独立T1测试采用显式 `|g⟩⟨e|`；官方教程复现保留其原sigmam约定并说明差异。

## 3. Rabi：在两个基矢之间来回转移

在旋转坐标系和旋转波近似下，使用ℏ=1：

```text
H = (Δσz+Ωσx)/2
Ω_R = sqrt(Ω²+Δ²)
初态|0⟩时 P_1(t)=Ω²/(Ω²+Δ²) × sin²(Ω_R t/2)
⟨σz⟩=1−2P_1(t)
共振Δ=0时 P_1=sin²(Ωt/2), ⟨σz⟩=cos(Ωt)
π脉冲时间t_π=π/Ω
```

推导提示：令 `n·σ=(Ωσx+Δσz)/Ω_R`，利用 `(n·σ)²=I`，完全重复第1周指数推导。失谐既增大振荡频率，也把转移峰值压到 `Ω²/(Ω²+Δ²)`，所以“更快”不等于“更有效”。

最小代码：

```python
import numpy as np
import qutip as qt
t = np.linspace(0, 4*np.pi, 601)
H = qt.sigmax()/2
result = qt.sesolve(H, qt.basis(2,0), t, e_ops=[qt.sigmaz()])
z = np.asarray(result.expect[0])
print(np.max(abs(z-np.cos(t))))
```

完整脚本使用更严格容差、关闭自动输出归一化以显示真实漂移，并保存CSV、PNG、PDF与指标JSON。实验室系选做部分为 `H_lab=−ω0σz/2+Ωcos(ω0t)σx`，明确保留Ω的幅度，并用内部步长解析快振荡。不要把输出点加密误认为积分器步长也随之变小。

## 4. 密度矩阵和耗散

纯态 `ρ=|ψ⟩⟨ψ|`。混合态 `ρ=Σp_i|ψ_i⟩⟨ψ_i|`，反映统计混合；不能把概率p_i直接当作纯态振幅叠加。

```text
dρ/dt = −i[H,ρ] + Σ_C (CρC†−{C†C,ρ}/2)
```

若 `C=sqrt(γ)|g⟩⟨e|`、无驱动，激发态布居 `P_e(t)=exp(−γt)`。若 `C=sqrt(γφ/2)σz`，无驱动时非对角元衰减率是γφ；若写 `sqrt(g)σz`，非对角元衰减率就是2g。因子2经常造成“图对不上”。

## 5. 官方教程001–003怎么跟做

原始教程已带许可证保存在 `third_party/qutip_tutorials/`。本项目的独立复现入口是 `code/week02_tutorials.py`；可逐格运行的版本在 `notebooks/`。

| 教程 | 对应动手 | 本项目验证 |
|---|---|---|
| 001 QobjEvo | 用函数、字符串、数组写同一H(t)，改变参数 | 任意探针时刻的算符一致；数组检查插值误差 |
| 002 Larmor | 初态(2|0⟩+|1⟩)/sqrt(5)，恒定、线性、周期磁场 | 三种进动角均与积分解析结果对照，Bloch半径=1 |
| 003 Qubit dynamics | 驱动退相干、倾斜场下三种Bloch轨迹 | 精确解、迹=1、厄米性、最小本征值及独立T1/T2基准 |

001使用当前Python风格回调 `f(t,parameter)`；字符串系数禁用Cython编译，省去编译器依赖。数组系数在节点间会插值，所以检查点包括非采样时刻。

002初态Bloch向量为(0.8,0,0.6)。对 `H=f(t)σz`，转角 `θ=2∫f(t)dt`，因此 `⟨σy⟩=0.8 sin θ`。三种角为2t、0.3t²、4sin(t/2)。系数2来自H的定义，不是求解器错误。

003原例 `H=δσx/2, C=sqrt(g)σz` 满足：

```text
z''+2g z'+δ²z=0, z(0)=1, z'(0)=0
ν=sqrt(δ²−g²)，欠阻尼时
z(t)=exp(−gt)[cos(νt)+(g/ν)sin(νt)]
```

教程里的 `exp(−gt)cos(δt)`适合g≪δ时的近似，不是精确解。脚本同时画两者并量化差异。C是σz退相干通道；在存在σx驱动时它仍影响系统能量，不能仅凭“纯退相干”一词把完整受驱过程的能量变化一概排除。

## 6. 热态分布的推导与截断

热平衡 `ρ=exp(−βH)/Z`。所有能级共同的零点能因子在归一化时消去。令 `q=exp(−βℏω)=nbar/(1+nbar)`：

```text
Z（去掉共同因子）=Σ_(n=0)^∞ q^n=1/(1−q)
P(n)=(1−q)q^n=nbar^n/(1+nbar)^(n+1)
⟨n⟩=q/(1−q)=nbar
```

分布是单模玻色热态的几何分布，平均占据数服从Bose–Einstein公式。截断成N层后，漏掉的总概率恰好是 `q^N`。两种QuTiP方法区别：

```text
method='analytic': p_n=(1−q)q^n, trace=1−q^N
method='operator': p_n=(1−q)q^n/(1−q^N), trace=1
截断归一化平均数 = nbar − N q^N/(1−q^N)
```

nbar=3、N=20时漏概率约0.00317，平均数约2.9364，不能声称完全等于3。本项目采用N=100，并给N=20、40、80、100收敛表。零温nbar=0时单独验证回到真空。

动手：把nbar设成10，先估计需要多大N使 `q^N<10⁻⁸`，再运行验证平均数误差；注意平均数误差可能比漏概率大N倍，选择N时两个指标都要看。
