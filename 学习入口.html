第1周：谐振子定态与矩阵指数推导

这是可供你理解、复算的推导讲义。原计划要求的个人手推照片应由你亲自完成，放进本周目录；讲义不能代替闭卷手推。

1. 从有单位方程到无量纲方程

一维谐振子哈密顿量为 H=p²/(2m)+mω²x_phys²/2，量子动量为 p=-iℏ d/dx_phys。定态满足：

[-ℏ²/(2m) d²/dx_phys² + mω²x_phys²/2] ψ = E ψ
ℓ = sqrt(ℏ/(mω)), ξ = x_phys/ℓ, ε = E/(ℏω)
[-1/2 d²/dξ² + ξ²/2] φ(ξ) = ε φ(ξ)
ψ_phys(x_phys) = φ(ξ)/sqrt(ℓ)

最后一行保证概率不变：|ψ_phys|² dx_phys = |φ|² dξ。程序变量x就是ξ，图上的能量单位是ℏω。本项目采用无量纲单位，不代表真实世界的ℏ等于1。

2. 中心差分如何变成矩阵

把区间设为 [-L,L]，取M个小区间，间距 h=2L/M。固定边界 φ(-L)=φ(L)=0。内部格点 j=1,...,M-1：

φ''(x_j) ≈ [φ_(j+1)-2φ_j+φ_(j-1)] / h²
H_jj     = 1/h² + x_j²/2
H_j,j±1  = -1/(2h²)
H v_n    = ε_n v_n

只有主对角与两条邻对角非零，所以用 scipy.linalg.eigh_tridiagonal，无需构造大型稠密矩阵。得到M−1维本征矢后补上两个零端点。

差分近似的局部误差是O(h²)。在边界误差已经很小时，把h减半，本征能量误差应约变为1/4。程序报告4组网格以及误差比；不是只展示一组“漂亮的能量”。

3. 离散归一化与连续归一化

对角化器默认 Σ|v_j|²=1；物理波函数需要 ∫|φ|² dx=1。均匀网格上大致有 φ_j≈v_j/sqrt(h)；本程序用数值积分统一归一化，更便于检验。

由于本征矢整体相位任意，数值结果可能恰好是解析解的负数。先计算重叠积分，若为负就整体乘−1，再计算L2误差。

L2误差 = sqrt(∫|φ_num - φ_exact|² dx)
能量绝对误差 = |ε_num - (n+1/2)|

4. 前三个解析本征态

ε_n = n+1/2
φ_n(x) = H_n(x) exp(-x²/2) / [π^(1/4) sqrt(2^n n!)]
H_0=1, H_1=2x, H_2=4x²-2
φ_0=π^(-1/4) exp(-x²/2)
φ_1=sqrt(2) x φ_0
φ_2=(2x²-1) φ_0 / sqrt(2)

n=0、1、2的节点数分别为0、1、2；宇称分别为偶、奇、偶。节点与对称性是独立于能量的检验。基态 ⟨x²⟩=1/2，以后会与第2周的零点涨落相互印证。

5. 网格误差和盒长误差不能混在一起

脚本默认L=8、M=800，即h=0.02。网格收敛固定L，改变M。边界检查固定h=0.02，改变L=3、4、6、8。L太小时波函数尾部被墙截断，h再小也无法恢复无限空间的答案。

本次验收：前三态能量最大误差<2×10⁻⁴、波函数L2误差<2×10⁻⁴、网格减半误差比在3.8–4.2。实际数值见 reports/verification.md。若改成高激发态，必须相应增加L及网格密度，不能沿用这组阈值就宣布正确。

6. 矩阵指数小测推导

对二能级模型 H=Ωσx/2、ℏ=1，σx²=I。把指数级数按奇偶次分开：

U(t) = exp(-iHt)
     = I cos(Ωt/2) - i σx sin(Ωt/2)
|ψ(0)⟩=|0⟩ → |ψ(t)⟩=cos(Ωt/2)|0⟩ - i sin(Ωt/2)|1⟩
P_1(t)=sin²(Ωt/2), ⟨σz⟩=1−2P_1=cos(Ωt)
U†U=I

第2周：升降算符、模式与零点涨落

先复习 Griffiths 第2章谐振子代数解法，再读 Gerry & Knight 第2章前半。教材正文未随任务提供；以下是独立推导讲义，不冒充教材原文或逐页阅读记录。

1. 为什么要重新写谐振子

第1周在坐标空间离散微分方程。第2周选择“能量本征态”作基底：把一个态描述成各能级的概率振幅。微分算符被矩阵代替，光子数态正好适用。

[x,p]=iℏ
a = sqrt(mω/(2ℏ)) x + i p/sqrt(2mℏω)
a†= sqrt(mω/(2ℏ)) x - i p/sqrt(2mℏω)
[a,a†]=1
x = sqrt(ℏ/(2mω)) (a+a†)
p = -i sqrt(mℏω/2) (a-a†)

检验对易关系：令A、B分别是x与p的系数，[Ax+iBp,Ax−iBp]=−2iAB[x,p]=2ABℏ=1。

2. 能级、数态与产生湮灭

n̂=a†a, H=ℏω(n̂+1/2)
a|n⟩=sqrt(n)|n−1⟩
a†|n⟩=sqrt(n+1)|n+1⟩
|n⟩=(a†)^n|0⟩/sqrt(n!), a|0⟩=0
E_n=ℏω(n+1/2)

把a†a代回x、p表达式可得到 H=ℏω(a†a+1/2)。[n̂,a]=−a 说明a让能量少一份ℏω，a†增加一份。这些是算符，a|0⟩=0中的右边是零向量，不是基态 |0⟩。

“二次量子化”在这里是用模式的占据数和产生／湮灭算符描述状态；每个模式可以有0、1、2…个玻色激发。它不是在已经量子化的同一对象上再按一次按钮。

3. 模式为什么像谐振子

在线性电磁场中选定边界条件和正交模式，每个模式的幅度满足谐振子方程。量子化后每个模式带一对a、a†：

H_field = Σ_k ℏω_k (a†_k a_k + 1/2)
[a_k,a†_l]=δ_kl
|n_1,n_2,...⟩是各模式占据数态

一个光子表示某个模式多一份ℏω激发。“模式”还包括空间形状、频率、偏振等标签；不能简单地把不同模式等同于不同位置的小球。tensor把不同模式或模式与原子组合，系统总维数是各子系统维数的乘积。

例子：tensor(basis(6,2),basis(2,1))表示模式在n=2、二能级系统在第1基矢。tensor(num(6),qeye(2))只测模式光子数。子系统顺序必须一致。

4. 零点能与零点涨落

展开平方，注意算符不交换：

(a+a†)² = a² + aa† + a†a + (a†)²
⟨n|a²|n⟩=⟨n|(a†)²|n⟩=0
⟨n|aa†|n⟩=n+1, ⟨n|a†a|n⟩=n
所以 ⟨n|(a+a†)²|n⟩ = 2n+1

在数态中 ⟨x⟩=⟨p⟩=0，但二阶矩不为0：

Δx² = ℏ(2n+1)/(2mω)
Δp² = mℏω(2n+1)/2
E_0=ℏω/2, 真空中 ΔxΔp=ℏ/2

因此“零点涨落验证”与“零点能验证”相关但不相同：前者检查方差，后者检查H期望值。本项目两者都做了。无量纲 X=(a+a†)/sqrt(2)、P=−i(a−a†)/sqrt(2) 时，真空方差各为1/2，方差的乘积为1/4，标准差的乘积为1/2。别把两种乘积混淆。

5. 有限矩阵不可能严格满足[a,a†]=I

任何有限矩阵的对易子迹为0，而I的迹为N，两者不可能恒等。截断基 |0⟩,...,|N−1⟩ 中：

[a,a†] = I − N |N−1⟩⟨N−1|

对远离最高层的数态，期望仍符合无穷维公式；最高态会失败。N=20时，最高态n=19的平方期望为19，不能误用2n+1=39。程序特意展示这个边界反例，并阻止把最高层放进常规验证范围。

动手：选N=8，打印a、a†及对易子的对角；预测最后一个元素是−7；把验证态n从0逐步加到7，解释哪里开始偏离。

NumPy数组的 * 为逐元素乘法、@ 为矩阵乘法；QuTiP Qobj 的 * 是算符乘法。把 .full() 取出的NumPy数组继续相乘时要换回 @。

2. 基态约定必须自己定义

basis(2,0)本身只叫 |0⟩，不天然意味着能量基态。若自由哈密顿量 H0=ω0 σz/2，|0⟩能量+ω0/2，反而更高；若取 H0=−ω0 σz/2，|0⟩才是基态。

QuTiP的 sigmam() 矩阵为 [[0,0],[1,0]]，把|0⟩送到|1⟩。若选择g=|0⟩、e=|1⟩，衰减算符应直接写 g*e.dag()；不要不看约定就使用sigmam。本项目的独立T1测试采用显式 |g⟩⟨e|；官方教程复现保留其原sigmam约定并说明差异。

3. Rabi：在两个基矢之间来回转移

在旋转坐标系和旋转波近似下，使用ℏ=1：

H = (Δσz+Ωσx)/2
Ω_R = sqrt(Ω²+Δ²)
初态|0⟩时 P_1(t)=Ω²/(Ω²+Δ²) × sin²(Ω_R t/2)
⟨σz⟩=1−2P_1(t)
共振Δ=0时 P_1=sin²(Ωt/2), ⟨σz⟩=cos(Ωt)
π脉冲时间t_π=π/Ω

推导提示：令 n·σ=(Ωσx+Δσz)/Ω_R，利用 (n·σ)²=I，完全重复第1周指数推导。失谐既增大振荡频率，也把转移峰值压到 Ω²/(Ω²+Δ²)，所以“更快”不等于“更有效”。

最小代码：

import numpy as np
import qutip as qt
t = np.linspace(0, 4*np.pi, 601)
H = qt.sigmax()/2
result = qt.sesolve(H, qt.basis(2,0), t, e_ops=[qt.sigmaz()])
z = np.asarray(result.expect[0])
print(np.max(abs(z-np.cos(t))))

完整脚本使用更严格容差、关闭自动输出归一化以显示真实漂移，并保存CSV、PNG、PDF与指标JSON。实验室系选做部分为 H_lab=−ω0σz/2+Ωcos(ω0t)σx，明确保留Ω的幅度，并用内部步长解析快振荡。不要把输出点加密误认为积分器步长也随之变小。

4. 密度矩阵和耗散

纯态 ρ=|ψ⟩⟨ψ|。混合态 ρ=Σp_i|ψ_i⟩⟨ψ_i|，反映统计混合；不能把概率p_i直接当作纯态振幅叠加。

dρ/dt = −i[H,ρ] + Σ_C (CρC†−{C†C,ρ}/2)

若 C=sqrt(γ)|g⟩⟨e|、无驱动，激发态布居 P_e(t)=exp(−γt)。若 C=sqrt(γφ/2)σz，无驱动时非对角元衰减率是γφ；若写 sqrt(g)σz，非对角元衰减率就是2g。因子2经常造成“图对不上”。

6. 热态分布的推导与截断

热平衡 ρ=exp(−βH)/Z。所有能级共同的零点能因子在归一化时消去。令 q=exp(−βℏω)=nbar/(1+nbar)：

Z（去掉共同因子）=Σ_(n=0)^∞ q^n=1/(1−q)
P(n)=(1−q)q^n=nbar^n/(1+nbar)^(n+1)
⟨n⟩=q/(1−q)=nbar

分布是单模玻色热态的几何分布，平均占据数服从Bose–Einstein公式。截断成N层后，漏掉的总概率恰好是 q^N。两种QuTiP方法区别：

method='analytic': p_n=(1−q)q^n, trace=1−q^N
method='operator': p_n=(1−q)q^n/(1−q^N), trace=1
截断归一化平均数 = nbar − N q^N/(1−q^N)

nbar=3、N=20时漏概率约0.00317，平均数约2.9364，不能声称完全等于3。本项目采用N=100，并给N=20、40、80、100收敛表。零温nbar=0时单独验证回到真空。

动手：把nbar设成10，先估计需要多大N使 q^N<10⁻⁸，再运行验证平均数误差；注意平均数误差可能比漏概率大N倍，选择N时两个指标都要看。

常用启动

在项目根目录右键 → 在终端打开，运行：

& '.\run_all.ps1'

若终端执行策略限制脚本，直接调用Python，不修改执行策略：
